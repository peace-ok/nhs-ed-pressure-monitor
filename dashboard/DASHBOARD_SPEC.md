# Dashboard specification

Four pages plus a data-quality page. Same structure discipline as the
companion TfL project.

## 1. National overview
- Total attendances (Type 1 and all-types, clearly labelled)
- Emergency admissions
- Type 1 four-hour performance trend (headline shown for reconciliation)
- Twelve-hour waits (single definition per chart; basis labelled)

## 2. Provider comparison
- Type 1 performance ranking WITHIN volume terciles (never a single
  national league table)
- Current vs previous year
- Headline-flattery gap: which trusts' all-types figures most flatter
  their Type 1 reality
- Persistent-pressure flags (>= 10 of 12 months below peers)

## 3. Pressure relationships
- Attendance growth vs four-hour performance (scatter)
- Admission rate vs performance
- Bed occupancy vs performance (QUARTER level; annotate "ecological
  association — not causal")
- Winter (Dec-Feb) vs rest of year

## 4. Data quality
- Completeness by organisation
- Missing/suppressed periods
- Merged-series organisations and treatment
- Load log: revisions applied
- Metric-definition changes marked on all time axes
